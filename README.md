# ahmed-abdelhafez98.github.io

Personal site of Ahmed Emad. Built with [Astro](https://astro.build), deployed to GitHub Pages on every push to `main`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

Content lives in Markdown:

- `src/content/projects/*.md` — one file per project
- `src/content/experience/*.md` — one file per role
- `src/data/site.ts` — name, links, skills, timeline
